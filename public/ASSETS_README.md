# VIDEO PORTFOLIO ASSETS GUIDE

To customize this creative video editor portfolio, place your actual video and poster image files inside the corresponding subdirectories here.

## 1. PROJECT PREVIEW VIDEOS (Muted, short, fast-loading MP4s)

Place these in the `/public/videos/` folder:
- `/public/videos/placeholder-preview-1.mp4` (Used for "UNTITLED FASHION FILM")
- `/public/videos/placeholder-preview-2.mp4` (Used for "COMMERCIAL SPOT")
- `/public/videos/placeholder-preview-3.mp4` (Used for "DOCUMENTARY SHORT")
- `/public/videos/placeholder-preview-4.mp4` (Used for "MUSIC VIDEO")

## 2. BEFORE/AFTER VIDEOS

Place these in the `/public/videos/` folder:
- `/public/videos/placeholder-raw.mp4` (RAW footage for color grade/edit comparison)
- `/public/videos/placeholder-final.mp4` (FINAL processed footage for comparison)

## 3. RHYTHM SECTION VIDEOS (Demonstration loops)

Place these in the `/public/videos/` folder:
- `/public/videos/timeline-cutting.mp4` (Short visual demonstrating cutting pacing)
- `/public/videos/timeline-color.mp4` (Short loop showing grading adjustment)
- `/public/videos/timeline-sound.mp4` (Loop showing audio waves / impact)
- `/public/videos/timeline-motion.mp4` (Loop demonstrating dynamic transitions/movement)
- `/public/videos/timeline-story.mp4` (Loop showing narrative composition)

## 4. HERO VIDEO BACKGROUND

Place this in the `/public/videos/` folder:
- `/public/videos/hero-showreel.mp4` (Cinematic montage playing behind the intro text)

## 5. POSTER IMAGES (Static frames shown while videos load)

Place these in the `/public/images/` folder:
- `/public/images/poster-1.jpg`
- `/public/images/poster-2.jpg`
- `/public/images/poster-3.jpg`
- `/public/images/poster-4.jpg`
- `/public/images/before-after-raw-poster.jpg`
- `/public/images/before-after-final-poster.jpg`
- `/public/images/hero-poster.jpg`

## HOW TO UPDATE PROJECT INFORMATION

All metadata (titles, descriptions, categories, case studies, dates) are separated from the code. Open the `src/data/projects.ts` file to easily edit or add projects.
